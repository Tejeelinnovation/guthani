## About the Experience

ANUROOP is a premium, fully responsive Indian-wear fashion experience built around **luxury editorial design + festive storytelling + smooth motion + direct customer enquiry**.

### Highlights

- Cinematic luxury hero experience
- Premium responsive navigation
- Sarees, lehengas, suits, kurta sets and festive edits
- Editorial collection layouts
- New arrivals and product showcases
- Product quick-view interactions
- Immersive lookbook sections
- Craftsmanship storytelling
- Instagram-inspired social content
- Testimonials and brand-value sections
- Smooth Framer Motion interactions
- Mobile-first responsive layouts
- WhatsApp-focused enquiry journey
- GitHub Pages-ready production build

## Tech Stack

`React` · `Vite` · `Tailwind CSS` · `Framer Motion` · `Lucide React`

## Deployment

Deployment is automated through GitHub Actions:

1. Install dependencies with `npm ci`
2. Build the Vite production bundle
3. Preserve GitHub Pages-compatible asset paths
4. Upload the `dist` artifact
5. Deploy to GitHub Pages

The Vite build also uses a single-file production strategy so the main design, styling and JavaScript remain bundled reliably for the project-site URL.

## Important Demo Note

The current repository contains demo fashion imagery and placeholder brand contact details for preview purposes. Before using this as Anuroop's final commercial website, replace those placeholders with the client's verified product photography, WhatsApp number, Instagram handle and official contact information.
